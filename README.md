# Atelier — Landing de Diseño de Interiores

Landing page demo para un estudio de diseño de interiores.

## Qué resuelve

Presenta el estilo y portafolio de proyectos de un estudio de decoración de interiores, con formulario de contacto para solicitar una consulta.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (formulario de contacto)

## Estado

Demo de portafolio.
